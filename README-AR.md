# Mi5G TV لـ iOS (نسخة تجريبية)

1. ارفع كل ملفات هذا المجلد إلى مستودع GitHub جديد (الفرع main).
2. افتح تبويب Actions ← Build IPA ← Run workflow.
3. بعد انتهاء البناء نزّل الملف Mi5GTV-unsigned-ipa من قسم Artifacts.
4. فك الضغط لتحصل على Mi5GTV-unsigned.ipa ووقّعه بشهادتك ثم ثبّته.

المميزات الحالية: اتصال بالتلفاز عبر ADB (المنفذ 5555)، ريموت، إرسال نص، مدير تطبيقات،
تسريع، إرسال رابط، لقطة شاشة، إعادة تشغيل.
